# EduTrack – Smart Student Information Management System

EduTrack is a desktop-based Student Information Management System developed using C++, Qt Creator, and MySQL. It helps manage student records efficiently through a simple and user-friendly graphical interface.

## Features

- User Login and Signup Authentication
- Add Student Records
- Edit Student Details
- Delete Student Records
- Search and Filter Students
- Dashboard with Course and Year Statistics
- Export Student Data to CSV
- Input Validation
- MySQL Database Integration
- User-Friendly Graphical Interface

## Technologies Used

- C++
- Qt Framework
- Qt Creator
- MySQL
- QODBC / ODBC
- CMake

## Database

The project uses MySQL as the backend database with two main tables:

- **Users** – Stores user authentication information.
- **Students** – Stores student information such as name, roll number, course, year, email, and phone number.

## Objective

The objective of EduTrack is to reduce manual work in student record management and provide an efficient, organized, and user-friendly system for storing and managing student information.
